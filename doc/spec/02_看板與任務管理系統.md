# 第三章：看板與任務管理系統

## 3.1 看板架構與資料模型

```typescript
export interface Board {
  id: string;
  project_id: string;
  title: string;
  position: number;
  description?: string;
}

export interface BoardColumn {
  id: string;
  board_id: string;
  name: string;
  wip_limit: number; // 0 代表不限制在製品數量
  position: number;
}
```

---

## 3.2 在製品限制 (WIP Limit) 規則與防呆
1. **限制設定**：專案經理與系統管理員可於各欄位設定 `wip_limit`。
2. **超標告警機制**：
   - 當欄位中任務卡片數量超過 `wip_limit` 時，欄位標題與卡片邊框呈現警告色（Amber/Rose）。
   - 系統自動產生一則類型為 `WIP_LIMIT_ALERT` 之全域通知，提醒團隊優先消化在製品，維持精實流程（Lean Flow）。

---

## 3.3 任務卡片 (Task) 規格

```typescript
export interface Task {
  id: string;
  column_id: string;
  title: string;
  description: string;
  priority: Priority;               // 'LOW' | 'MEDIUM' | 'NORMAL' | 'HIGH' | 'URGENT'
  assignee_id: string | null;
  collaborators: string[];
  position: number;
  due_date: string | null;
  estimated_hours?: number;
  tags: string[];
  module_category: string;
  created_at: string;
}
```

### 操作特性：
- **拖曳排序**：支援跨欄位拖曳與同欄位垂直排序，更新後自動計算 `position`。
- **卡片詳情模態窗 (TaskModal)**：
  - 任務標題、富文本描述編輯。
  - 優先級調整、責任人指派、標籤增刪。
  - 工時預估與截止日期變更。
  - 附件清單與截圖貼上支援。
  - 任務留言評論串 (TaskComment)。

---

## 3.4 甘特圖 (Gantt Chart) 時間軸排程
- 提供切換甘特圖檢視模式。
- 以時間軸方式排程各任務的進度、到期日與耗時預估，提供專案整體進度之鳥瞰視圖。
