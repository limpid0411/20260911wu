# 06. 午餐訂購管理系統規格說明 (doc/spec/06_午餐訂購管理系統.md)

- **模組名稱**：午餐訂購管理系統 (Lunch Order Management)
- **版本**：v1.0.0
- **分支**：`feat/lunch-order`
- **維護日期**：2026-09-11

---

## 1. 系統簡介與應用場景

「午餐訂購管理系統」旨在協助工程與專案團隊於日常作業中快速發起便當、簡餐與手搖飲之團隊團購活動。透過自動化計算小計金額、提供同仁線上選擇菜單與客製化備註，並具備對帳付款狀態切換開關，徹底解決過去人工統計容易出錯與漏收餐費的問題。

## 3. REST API 規格

- **`GET /api/lunch/restaurants`**：取得所有店家與菜單列表。
- **`POST /api/lunch/restaurants`**：新增合作店家與自訂菜單。
- **`PUT /api/lunch/restaurants/:id`**：更新現有合作店家名稱、電話、分類與自訂菜單價格。
- **`GET /api/lunch/orders`**：取得所有午餐團購活動及其明細。
- **`POST /api/lunch/orders`**：發起新午餐/飲料團購。
- **`PUT /api/lunch/orders/:id/status`**：更新團購狀態 (`OPEN` / `CLOSED` / `ORDERED`)。
- **`POST /api/lunch/orders/:id/items`**：同仁點餐與加點。
- **`PUT /api/lunch/items/:id/paid`**：切換同仁付款狀態 (`is_paid`)。
- **`DELETE /api/lunch/items/:id`**：刪除點餐明細。

## 4. UI 介面設計規範

1. **頂部數據橫幅與 KPI**：實時顯示「登記中團購數」、「累積訂購份數」、「總金額」與「待結清未付款金額」。
2. **團購單列表與詳情視窗**：左側列出所有歷史與進行中團購；右側顯示當前選擇團購之店家電話、截止時間與線上點餐表單。
3. **同仁對帳表格**：清楚標示每一筆點餐項目之品名、數量、小計、客製化備註，並配有綠/紅高亮之「已付款/未付款」一鍵切換按鈕。
4. **店家與菜單即時修改**：在店家維護視窗中，同仁可點選現有店家卡片上的「修改」按鈕，即時回填編輯並保存至 SQLite，支援修改電話、分類與菜單價格。
