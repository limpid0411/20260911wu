# 第一章：系統規格總覽與架構導引

## 1.1 系統定位與目標
「企業級專案管理系統 (Enterprise PMS & RFI)」為一針對工程建設、軟體交付與企業跨部門協作設計的一體化管理平台。核心聚焦於：
1. **工程看板與任務追蹤**：提供直覺式看板視圖與甘特圖時間軸，並引入在製品限制（WIP Limit）防止工作堆積。
2. **RFI 工務資訊詢答管理**：將傳統工程中的工程問題澄清單（Request For Information）數位化，支援工期/成本影響審查、多級狀態機審批與不可竄改之審計稽核日誌。
3. **附件與螢幕截圖快速協作**：支援剪貼簿直接貼上截圖（Ctrl+V）、檔案預覽燈箱（Lightbox）。
4. **細粒度角色權限（RBAC）**：區分管理員、專案經理、成員與外部審查員，並具備即時身分切換測試體驗。


## 1.4 本地運維與啟動/關閉雙腳本規格

為落實純本地電腦零配置運行，專案根目錄提供標準啟動與關閉雙腳本，完全相容 Windows 10 / 11 系統：

| 腳本名稱 | 運作機制 | 規格特色 |
| :--- | :--- | :--- |
| **`start.bat`** | 啟動本地 Vite 開發伺服器 | 1. 自動偵測本機 Node.js 環境。<br>2. 自動檢測並補裝 `node_modules` 套件庫。<br>3. 啟動前自動檢測並強制釋放 3000 連接埠衝突。<br>4. 自動喚醒預設瀏覽器導向 `http://localhost:3000`。<br>5. 常駐伺服器日誌終端視窗。 |
| **`stop.bat`** | 一鍵關閉本地伺服器 | 1. 繞過系統 PowerShell 權限限制（ExecutionPolicy Bypass）。<br>2. 準確終止佔用 3000 連接埠之程序與 Node 執行序。<br>3. 自動精準清理關閉標題為「企業級專案管理系統伺服器」之終端機視窗。<br>4. 釋放連接埠後提供綠色成功訊息反饋。 |
