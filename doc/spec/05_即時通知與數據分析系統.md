# 第六章：即時通知與數據分析系統

## 6.1 系統通知模型 (Notification)

```typescript
export interface Notification {
  id: string;
  user_id?: string;
  type:
    | 'WIP_LIMIT_ALERT'
    | 'RFI_OVERDUE'
    | 'RFI_CREATED'
    | 'RFI_STATUS_CHANGED'
    | 'TASK_ASSIGNED'
    | 'COMMENT_ADDED'
    | 'TASK_MOVED'
    | 'ATTACHMENT_UPLOADED'
    | 'WIP_WARNING';
  title: string;
  message: string;
  is_read: boolean;
  created_at: string;
}
```

### 通知觸發來源：
- 看板任務卡片移入超過 WIP 限額之欄位。
- 新建立 RFI 或指派審查員。
- 審查員填寫官方回覆或經理將 RFI 結案。
- RFI 逾期未回覆警示。

---

## 6.2 專案數據分析儀表板 (ProjectAnalytics)
系統提供獨立之數據分析分頁：
1. **任務健康度分析**：
   - 各欄位任務分布比率。
   - 逾期未完成任務卡片占比與警示清單。
2. **RFI 處理效能指標**：
   - 累計 RFI 數量與各狀態分布長條圖。
   - 平均回覆耗時統計。
   - 累計工期影響天數與成本追加預警。
3. **團隊工作負荷評估**：
   - 各成員目前承接之任務與 RFI 案件數量。
