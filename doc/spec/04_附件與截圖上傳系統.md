# 第五章：附件與截圖上傳系統

## 5.1 附件資料結構

```typescript
export interface Attachment {
  id: string;
  target_type: 'TASK' | 'RFI' | 'COMMENT'; // 關聯目標主體
  target_id: string;                       // 目標主體 ID
  file_name: string;
  file_size: number;
  file_url: string;                        // Base64 或物件存儲 URL
  mime_type: string;
  uploader_id: string;
  uploader_name: string;
  created_at: string;
  is_clipboard?: boolean;                  // 是否為剪貼簿直接貼上截圖
}
```

---

## 5.2 剪貼簿截圖直接貼上機制 (ClipboardUploadHelper)
1. **事件監聽**：於任務卡片模態視窗與 RFI 詳情頁掛載全域 `onPaste` 事件。
2. **圖像判定**：讀取 `event.clipboardData.items`，過濾出 `type.startsWith('image/')` 之項目。
3. **自動處理**：
   - 提取 Blob 物件並轉成 DataURL (Base64) 存入本地儲存。
   - 自動產生名稱如 `clipboard_20260911_143000.png`。
   - 標記 `is_clipboard: true`。
   - 無需手動另存檔案再點選選取檔案按鈕，極大化現場工程師回報效率。

---

## 5.3 燈箱預覽組件 (LightboxModal)
- 支援圖片放大預覽、旋轉、原始大小與適應視窗顯示。
- 提供鍵盤快速鍵（<kbd>Esc</kbd> 關閉、方向鍵切換前後張圖片）。
