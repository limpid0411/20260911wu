# 開發計畫區 (Development Plans)

本目錄存放所有**新功能開發前**的計畫檔案。

---

## 📌 命名規範

所有計畫檔案名稱必須嚴格遵循以下格式：
```text
plan_<功能名稱>.md
```
例如：
- `plan_task_filtering.md`（任務卡片進階篩選功能）
- `plan_rfi_pdf_export.md`（RFI 表單匯出 PDF 功能）
- `plan_gantt_milestone.md`（甘特圖里程碑標記功能）

---

## 📝 開發前流程說明

1. **先討論**：與使用者／專案負責人對齊需求細節、UI/UX 互動行為與資料結構變更。
2. **寫計畫**：以 `plan_template.md` 為基準，建立 `plan_<功能名稱>.md`。
3. **參照執行**：在開發過程中，以此計畫為基準進行編程，避免範圍蔓延（Scope Creep）或脫離架構設計。
4. **回寫規格**：功能完成後，將正式規格寫回 `doc/spec/` 相關章節，並在計畫檔案末尾勾選完成狀態。
